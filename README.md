One word — the first thought that comes to mind. Built for the [make.fun](https://make.fun/c/u-0xkianno-one-word-first-thought-106abaf8) bounty "One Word, First Thought".

The program writes the word to `/output/entry.txt`:

> Marmalade

Why Marmalade: the first honest thought of a slow morning — vivid, specific, real.

Run it with Python 3:

```sh
python3 main.py
```
